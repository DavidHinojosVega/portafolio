Sistema de Inventario de TI

Soporte TI · Desarrollo Web · Safran Cabin Chihuahua

Sistema web interno que desarrollé para el departamento de TI. Centraliza el inventario de computadoras, laptops, monitores, tablets, celulares, telefonía, impresoras y equipos de red, y sustituye el control que antes se llevaba en hojas de cálculo separadas. Hoy lo usan TI y Recursos Humanos.

Funciones
  • Inventario por tipo de equipo, con responsable, ubicación y estado
  • Historial de asignaciones y cartas responsivas con firma digital
  • Resguardo de claves BitLocker y verificación mensual de parches
  • Control de garantías, etiquetas QR, importación desde Excel y reportes
  • Maqueta 3D de los cuartos MDF y gabinetes IDF
  • Roles de acceso e interfaz en español e inglés
Tecnologías
  • ASP.NET Core — API REST
  • SQL Server
  • HTML, CSS y JavaScript
